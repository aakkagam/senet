# Senet

A free browser version of Senet, the ancient Egyptian board game — a race across 30 squares, moved by the throw of casting sticks. Two players, local hotseat. Part of [Aakkagam Games](https://games.aakkagam.com).

Live at **https://games.aakkagam.com/senet/** (coming soon)

## Status

Just started — this repo currently holds only the README. Implementation to follow.

## Stack (planned)

Svelte 5 + TypeScript + Vite, deployed to GitHub Pages at base `/senet/`, following the same pattern as the other Aakkagam games.
